# 定性研究方法学习进度追踪

**开始日期**: 2025-12-16
**学习目的**: 解决人类与人工智能拟人化行为分类工作中的方法论问题

---

## 核心问题与学习目标

### 问题一：分类体系缺乏理论依据 (0/6 已掌握)

**现状痛点**: 无法证明分类不是主观臆断

学习目标：
- [ ] 扎根理论的基本原理：如何从数据中归纳类别
- [ ] 开放式编码：识别初始概念的系统方法
- [ ] 类别饱和度判断：何时停止寻找新模式
- [ ] 理论抽样：如何选择下一批分析数据
- [ ] 记录分析轨迹：建立可追溯的决策链条
- [ ] 撰写方法论说明：向外部解释分类如何产生

**预期成果**: 能够说清楚每个类别是基于哪些数据证据、通过什么步骤归纳出来的

---

### 问题二：分类流程不可复制 (0/5 已掌握)

**现状痛点**: 依赖个人经验和直觉，换人就得重新摸索

学习目标：
- [ ] 编码手册设计：编写清晰的类别定义和操作化规则
- [ ] 编码流程标准化：开放编码、主轴编码、选择性编码的使用时机
- [ ] 编码员培训方案：如何让新人快速掌握编码标准
- [ ] 质量控制检查点：在流程中设置哪些验证环节
- [ ] 流程文档模板：建立标准作业程序文档

**预期成果**: 建立一套标准化的编码协议，新项目或新成员可直接复用

---

### 问题三：评估结果说服力不足 (0/4 已掌握)

**现状痛点**: 向人工智能公司或监管部门汇报时缺乏量化指标支撑

学习目标：
- [ ] 编码者间信度计算：科恩卡帕系数的原理和计算
- [ ] 克里彭多夫阿尔法系数：何时使用、如何解读
- [ ] 信度阈值标准：学术界和工业界的可接受水平
- [ ] 研究质量标准：可信度、可靠性、可转移性的证明方法

**预期成果**: 能在报告中提供量化的质量指标，增强方法的可信度

---

### 问题四：类别定义模糊、边界案例处理混乱 (0/5 已掌握)

**现状痛点**: 遇到模棱两可的案例不知道如何系统化处理

学习目标：
- [ ] 类别边界明确化：设定清晰的纳入和排除标准
- [ ] 边界案例处理规则：建立一致的决策框架
- [ ] 编码分歧解决机制：系统化的讨论和仲裁流程
- [ ] 典型案例库建设：为每个类别收集代表性例子
- [ ] 灰色地带文档化：记录难以归类案例的处理依据

**预期成果**: 建立明确的决策规则，减少编码过程中的随意性

---

## 已识别的知识盲区

**方法论基础薄弱**:
- 不清楚归纳式分析和演绎式分析的区别
- 不了解如何判断数据量是否充足
- 缺乏系统的质量标准认知

**量化评估能力缺失**:
- 不会计算编码者间信度
- 不知道什么样的信度值算合格
- 缺乏处理编码分歧的系统方法

**流程规范性不足**:
- 编码过程缺乏清晰的阶段划分
- 决策依据没有系统记录
- 难以向他人传授编码方法
