# 扎根理论关键术语中英文对照表

## 核心概念

| 术语 | 英文 | 定义 | 你的工作中的例子 |
|------|------|------|-----------------|
| **开放式编码** | Open Coding | 将原始数据分解成初始概念和代码，逐句逐段问"这是什么？" | 看"AI说：我很关心你"，标记出"情感声称"这个代码 |
| **主轴编码** | Axial Coding | 将相似的开放式代码分组并关联，形成类别及其维度 | 把"情感声称"、"同情表达"、"鼓励语言"都分到"情感模拟类" |
| **选择性编码** | Selective Coding | 从众多类别中找出核心类别，建立综合理论 | 发现核心类别："拟人化的多维策略设计" |
| **代码** | Code | 用来标记数据中有意义单位的标签 | "情感声称"、"权威装扮"等是代码 |
| **范畴/类别** | Category | 通过关联相关代码形成的中等抽象层次 | "情感模拟"是一个范畴，包含多个代码 |
| **核心类别** | Core Category | 其他所有类别都围绕它组织的中心概念 | 整个分析体系围绕"拟人化策略"这个核心 |

## 数据与理论发展

| 术语 | 英文 | 定义 | 你的工作中的例子 |
|------|------|------|-----------------|
| **理论抽样** | Theoretical Sampling | 基于已有分析结果有目的地选择下一批数据，而非随机抽样 | 发现"情感支持"类别还模糊，主动找30条相关对话深化理解 |
| **饱和度** | Saturation | 当新数据不再产生新的代码或类别时的状态 | 分析到500条对话后，新对话全部符合已有分类，无新类别产生 |
| **数据三角测量** | Data Triangulation | 用多种数据来源验证同一现象 | 用Label Studio标注数据 + 人工审核 + 不同编码员的标注 |
| **持续对比分析** | Constant Comparative Analysis | 不断比较新数据与已有代码，边分析边收集数据 | 每标注100条对话，回头检查是否要调整已有的分类 |

## 分析过程

| 术语 | 英文 | 定义 | 你的工作中的例子 |
|------|------|------|-----------------|
| **编码备忘录** | Memo/Memoing | 分析过程中关于想法、决策、疑问的文字记录 | 记录：为什么区分"情感声称"和"同情表达"？依据是什么？ |
| **编码手册** | Codebook | 系统地记录每个代码/类别的定义、操作规则和例子 | 对"情感声称"的详细说明：定义、判断标准、典型案例、边界案例 |
| **编码规则** | Coding Rules | 明确的操作指示，告诉人们什么时候应该使用某个代码 | 规则："只有当AI直接声称自己有情感时，才标记为'情感声称'" |
| **树形编码** | Tree Diagram/Coding Tree | 用图表展示代码、类别、核心类别的层次关系 | 一张图表显示：核心类别→各主要类别→各代码之间的关系 |

## 质量评估

| 术语 | 英文 | 定义 | 你的工作中的例子 |
|------|------|------|-----------------|
| **编码者间信度** | Inter-Rater Reliability | 多个编码员对同样数据的分类结果一致程度 | 2个编码员对100条对话的标注一致率 |
| **科恩卡帕系数** | Cohen's Kappa | 衡量编码者间一致性的统计指标，范围0-1 | κ = 0.85 表示一致性很高 |
| **一致性** | Agreement | 编码员标注结果相同的比例 | 2个编码员对同样100条数据的标注中，90条都一样 |
| **可信度** | Credibility | 研究结果真实反映了研究对象 | 分类确实反映了AI的拟人化行为，不是研究者的想象 |
| **可转移性** | Transferability | 研究结果能否应用到其他相似情境 | 用这个分类体系能否评估其他AI的拟人化行为？ |
| **可靠性** | Dependability | 研究过程和结果都有清晰的审计踪迹 | 能追溯每个分类的产生过程，而不是"黑盒" |

## 扎根理论的不同流派

| 流派 | 创始人 | 特点 | 适用情况 |
|------|------|------|----------|
| **经典扎根理论** | Barney Glaser | 强调发现、客观性、让数据"说话" | 当你希望结论完全来自数据，不受理论预设影响 |
| **程序化扎根理论** | Strauss & Corbin | 强调系统步骤、主轴编码、条件-后果分析 | 当你需要清晰的分析流程和结果呈现时（更适合你） |
| **建构主义扎根理论** | Kathy Charmaz | 承认研究者的价值观影响、更反思性 | 当你想明确讨论自己的立场和假设 |

## 常见的编码类型

| 类型 | 说明 | 例子 |
|-----|------|------|
| **一级代码** | 最基础的标签 | "使用第一人称"、"提供解决方案" |
| **二级代码** | 多个一级代码的分组 | "情感模拟"包含：情感声称 + 同情表达 + 鼓励 |
| **属性** | 代码的特征或维度 | "情感声称"的属性：强度（弱/中/强）、频率 |
| **维度** | 属性在不同情况下的变化 | 情感强度维度从"否认有情感"到"深度情感表达" |

## 你可能遇到的问题与术语

| 问题 | 对应术语 | 解释 |
|-----|---------|------|
| 怎么判断分类已经够了？ | 饱和度 Saturation | 当新数据不再产生新类别时 |
| 两个人标注结果不一样怎么办？ | 编码者间信度 Inter-Rater Reliability | 需要计算一致性，通常用Cohen's Kappa |
| 怎么让别人相信我的分类不是乱想的？ | 编码备忘录 + 编码手册 Memo + Codebook | 展示决策过程和明确规则 |
| 某条数据似乎可以标两个类别怎么办？ | 编码规则 Coding Rule | 建立清晰的优先级规则来消除歧义 |

## 快速参考：分析流程术语链

```
原始数据
    ↓ [开放式编码 Open Coding]

    ↓ [主轴编码 Axial Coding]

    ↓ [理论抽样 Theoretical Sampling]
    ↓ [检查饱和度 Check Saturation]

    ↓ [选择性编码 Selective Coding]

    ↓ [编码手册记录 Codebook + Memos]
可复现和可验证的分类体系
```

## 建议学习顺序

1. 先理解 **核心概念** 部分的表格
2. 学习 **数据与理论发展** 中的三个步骤（理论抽样→饱和度→对比分析）
3. 了解 **分析过程** 中的"编码备忘录"和"编码手册"（这些是你证明分类不是臆断的关键）
4. 查阅 **质量评估** 部分的"编码者间信度"和"可信度"
5. 参考 **常见编码类型** 来理解数据标注的层次结构

这份文档在你学习过程中要多次参考。
